# ishkuzai sites

Two static sites built from one small generator (`build.py`, Python 3.13, no dependencies):

- **hub**: the personal portfolio (ishkuzai): three pages, `home` (an introduction), `projects`
  (Eventide, Chrestomathia, Demiurge) and `contact` (email and accounts). Projects and contact now exist
  in all five languages; the Chrestomathia entry links to chrestomathia.org (`EXTERNAL` in `build.py`).
- **eventide**: the Eventide site (the "What is Eventide?" page and the word tracer)

## Build

    py -3.13 build.py          # local build, relative links; open dist\hub\index.html
    py -3.13 build.py --prod   # production build: absolute cross-site links and hreflang tags

Output goes to `dist\hub` and `dist\eventide`; each is a complete site, to be deployed separately.

## Content

    content\<site>\<page-id>\<lang>.md

Each file starts with a front-matter block:

    ---
    title: Page title (native script)
    nav: Short menu label (optional)
    romanised: Romanisation (required when the title is not Latin script; becomes the URL)
    lead: One-sentence introduction (optional)
    summary: Search-engine description
    origin: en          # the language this page was first written in
    ---

- A page may exist in any subset of languages; the language switcher lists only those that exist.
- URLs: English at the root (`/tongues/`), others under their code (`/de/sprachen/`, `/ru/jazyki/`).
- A language is added by adding its code to `LANGS` in `build.py` and its entries in `strings.json`
  and `laws.json`. Right-to-left languages go in `RTL`.
- `{{url:eventide:tongues}}` links to a page in the reader's language (English if missing).
- `{{ext:chrestomathia}}` and `{{ext:demiurge}}` are external project links; each stays plain text until its
  entry in `EXTERNAL` (in `build.py`) is set.
- `{{tracer}}` inserts the word tracer.

## Russian web addresses (`romanise_ru` in `build.py`)

Russian pages get their address from the title, in Jake's own accent-free, Slovak-like scheme.
It is for addresses only and never appears on the pages.

| Cyrillic | Address | | Cyrillic | Address |
|---|---|---|---|---|
| ч ц | c | | ё ѣ э | e |
| ш с | s | | ы й | y j |
| щ | sc | | ю я | ju ja |
| ж з | z | | ф ѳ ѵ | ph th y |
| х | ch | | ъ ь | not written |

Letters can merge (ч/ц → c, ж/з → z); the build stops if two pages in one language would
receive the same address.  Persian addresses are still given by hand (`romanised:`).
## Eventide look and the German Fraktur

- The Eventide pages are set as a printed leaf: vellum, iron-gall ink, rubric red, lapis; a
  classical meander band at the head and a folk lozenge band at the foot (both drawn inline in
  `assets\eventide.css`, so no image files).  The hub keeps its own plainer style.
- Typefaces by language: IM Fell English / EB Garamond (en, fr), Monomakh (ru: a Slavonic ustav face that
  carries the old letters; Old Standard TT and EB Garamond stand behind it), Amiri (fa), Grenze Gotisch with
  UnifrakturMaguntia (de).
- German pages are converted at build time by `fraktur_html()` in `build.py`: long s (ſ) at the
  start and inside syllables, round s at the end of a word or syllable (Königs|rat), ſſ for ss.
  In-world names (the `NAMES` set) and any word with non-German letters are set in Antiqua, as foreign
  words traditionally are.  Anything marked `lang="und"` (the tracer's transcriptions) is left alone.
  Wanting a different spelling for one word: add it to `NAMES` (Antiqua) or adjust `long_s`.
- Emphasis in German is letter-spaced rather than italic, as is Fraktur custom.
## Rules

- Chrestomathia (the release name of Targum) never links back to the creative projects. Nothing in these sites should link to it
  except from the hub (one way).
- The tracer data in `data\trace.json` is exported from the Eventide engine (`export_trace.py`
  alongside it in the engine folder); regenerate it only from the engine, never edit by hand.

## Hub look

The hub is a hung picture drawn from the folk-art and fine-art references in `C:\Users\jakes\Code\Aesthetics
(Reference)`. Behind every page is a painting of a stream in a sunlit forest (`assets\hub-bg.jpg`, fixed behind the
page; the foot is shaded for the inscription). On it, a bar of dark glass with the name, the menu and the
languages, and below it the text on parchment set in a woven rhombus band (Bilibin's page frames) with gilt rules.
`assets\hub.css` holds the colours as variables. The picture was generated by the author in NightCafe from a prompt based on Shishkin's paintings (personal use, no
licence to worry about); the signatures along its lower edge are generation artefacts and are cropped off
(2000 x 1092 px). To change it, replace `hub-bg.jpg`.
Type: Ruslan Display (page titles), Forum (headings, menu), Gentium Book Plus (text), all from Google Fonts;
Persian falls through to Noto Naskh Arabic. The Eventide site keeps its own look.

Each folder in `dist` is a complete site, with its own `CNAME` (GitHub Pages reads it) and `.nojekyll`. Publish each
as its own repository, with `py -3.13 build.py --prod` (folder-style links, absolute links between the sites).
At the registrar or at Cloudflare DNS, add a `CNAME` record for `nychthemeron` and one for `demiurge`, each pointing
at `<github-account>.github.io`; then set the custom domain in each repository's Pages settings.

### The Demiurge site

Three parts. The **introduction** and the **download** page are written by hand (`content\demiurge\home.md`,
`download.md`). The **reference** is generated from the project's own document,
`C:\Users\jakes\OneDrive\Documents\Demiurge\docs\Demiurge - Project Reference.md` (override the folder with the
`DEMIURGE_DOCS` environment variable): each numbered section (1 to 19) becomes a page with a contents list, links
between sections and a search box (`search.json`). Revise the document and rebuild to update the site.

- The public build leaves out the document's working notes: the legend, the change notes, the blockquotes marked
  as contradictions or reviews, the documentation housekeeping and the appendices. `py -3.13 build.py --internal`
  keeps them, for reading.
- Red "TO DO" headers become "Still to build" notes.
- The download page says "Not yet available" until `DOWNLOAD` in `demiurge_site.py` is set to the release address.
- **Look.** A painting of the sun breaking through swirling clouds (`assets\demiurge-bg.jpg`, generated by the author
  in NightCafe; copied to the site as `background.jpg`) is fixed behind every page, with the menu on a bar of dark
  glass and the text on plates of atlas paper ruled in gilt. The earlier orrery (an animated solar-system drawing)
  has been taken out.
- **Languages.** The language menu (top right) lists the project's 14 locales, from `content\demiurge\locales.json`
  (each with its own name, direction, and the draft translations of the few words used). English is the only one
  with content. In every other language the introduction and the reference say "Work in progress / Coming soon" and
  link to the English page, and the download page stays, with the note "Language not yet supported" above the
  English text. Translations of those words are drafts for a native speaker. To open a language, replace its three
  placeholder pages with real ones.
